OVERVIEW

7STEPの全体像と、この資料の使い方

AIで仕事を自動化するまでにやることは、分解するとこの7つだけです。

AI活用が続かない人は、だいたい同じ流れです。新しいツールを試す。すごいってなる。でも翌週には使ってない。仕事は何も変わってない。この7STEPは、それを防ぐための順番です。やること自体は、1個ずつ見るとめっちゃ簡単なので、上から順に進めてください。

STEP 1

AIに慣れる

ウェブのAIと話して、得意・不得意を肌感でつかむ。慣れたら Claude Code か Codex へ。

STEP 2

ツール理解

AI本体のまわりの便利ツールを先に知っておく。ここはガンガン課金しなくていい。

STEP 3

環境構築

AI専用のフォルダを作り、中を分けて、情報（ナレッジ）を入れる。AIの出力の差は、情報を渡せているかで決まります。

STEP 4

ツールを繋ぐ

API・MCP（外のサービスとAIをつなぐ窓口。STEP4で説明します）で、カレンダー・SNS・会計などパソコンの外の仕事も任せる。

STEP 5

スキル構築

一度やった作業を「仕事マニュアル」にして、一言で何回でも再現する。

STEP 6

定期自動実行

完璧になったスキルを、決めた時間に自動で動かす。

STEP 7

自律思考

AI同士が会話して自律的に動く世界。今は名前を知っておくだけでOK。

STEP 03

環境構築（フォルダ作成 → 中の分け方 → 情報を入れる）

Claude Code や Codex はパソコンの中の「フォルダ」で作業します。AIが正しく動ける場所を作りましょう。

先に2分半で、流れを掴む

▶ STEP3の3つの作業（フォルダを作る → 中を分ける → 情報を入れる）を約2分半で通しで解説しています。見てから下を順番にやると迷いません。

ナレーション全文を読む

STEP3、環境構築を、はじめから通しで解説します。やることは、フォルダを作る、中を分ける、情報を入れる、の3つだけです。1つずつ、そのまま真似してください。

そもそも、Claude CodeやCodexは、パソコンの中の「フォルダ」で作業するAIです。だから最初に、AIが正しく動けるように、AI専用の場所を用意してあげる必要があります。

最初にやることは2つです。1つ目は、Claude CodeかCodexを入れること。公式サイトからダウンロードして、指示どおりに進めるだけです。2つ目は、パソコンにAI専用のフォルダを1個作ること。名前は自由で、例えば「AI経営」でOKです。

実は、フォルダを作るのすら、AIに任せられます。Claude CodeやCodexは、パソコンのフォルダを直接触れるからです。アプリを開いて、こう指示してみてください。もちろん、自分で作ってもOKです。

次に、中の分け方です。AIの良い出力は、指示の質と、渡す情報の質の、掛け算で決まります。料理に例えると、指示は調理器具、情報は食材です。みんな指示は頑張るのに、情報の整理ができていない。だから、情報の置き場所を先に整えます。

フォルダ構造は、資料に置いてある「一撃で構築するプロンプト」を貼るだけで作れます。AIがあなたの仕事内容を質問しながら、事業部ごとのフォルダを作ってくれます。僕の環境だと、SNS事業部の中にYouTubeがあって、その中がリサーチ、企画、台本、サムネイル、撮影、編集、公開、分析と、仕事の順に並んでいます。

最後に、情報を入れます。メモを放り込むのも面倒だと思うので、ここもAIに任せましょう。情報を渡して、こう頼むだけです。ChatGPTのプロジェクトやNotebookLMに入れると、そのAIの中でしか使えません。自分のパソコン、つまりローカルに置けば、ClaudeでもCodexでも、どのAIからでも同じ資産が使えます。

ここまで来ると、AIの答えがあなた専用になってきます。今日は、フォルダを1個作るところまでで十分です。完璧を目指さなくて大丈夫。作れたら、次はSTEP4、ツールを繋ぐ、に進みましょう。

3-2. 中の分け方（フォルダ構造）

いきなりですが、AIの答えがイマイチな時って、何が原因だと思いますか？　指示出し、と思った方が多いはずです。これは違って、AIの回答がイマイチになる時は、僕たちが渡す情報がイマイチな時なんです。

そもそもAIの良い出力は、2つの要素の掛け算で出ます。1つ目がAIへの指示出しの質、つまりプロンプト。2つ目がAIに与える情報の質、ナレッジとか呼ばれます。料理に例えると、どれだけ良い調理器具を持っていても、使っている食材が賞味期限切れだったら、良い料理はできないじゃないですか。調理器具がプロンプト、食材がナレッジです。

情報をごちゃごちゃに渡してしまうと、AIが「情報はありがたいけど、どこを見ればいいの！？」と混乱してしまいます。なので情報を整理するために、フォルダの構造、つまり情報の置き場所を整理する必要があります。具体的には、まず事業部ごとのフォルダを作ります。

フォルダ構造を一撃で構築するプロンプト

フォルダ構造を一撃で作るプロンプトです。3-1で作ったAI専用フォルダ（例：AI経営）を Claude Code か Codex で開いた状態で貼ると、あなたの仕事内容をヒアリングした上で、AIが働きやすいフォルダ一式をその中に作ってくれます。

フォルダ構造 一撃構築プロンプト 
あなたに、私の仕事用フォルダの設計をお願いします。
これから、このフォルダをあなた（Claude Code / Codex）の作業場所として使います。

【やってほしいこと】
1. まず、次のことを私に1つずつ質問してください。
   - どんな事業・仕事をしているか（複数あれば全部）
   - よくやる作業（例: SNS投稿づくり、資料作成、経理、リサーチ）
   - すでに持っている情報・ファイルの種類（例: 過去の投稿、商品資料、お客様とのやり取り）

   - プロダクトナレッジ: 商品・サービス・お客様に関する情報

3-3. 情報（ナレッジ）を入れる

仕上げに、作ったフォルダの中に必要な情報、つまりナレッジを入れていきます。置き場所が決まったら、次は中身ってことですね。

そもそも、AIの答えが一般論で使えないのって、AIが悪いんじゃなくて、あなたの情報を何も知らないからなんですよ。僕がよく言っているのは KNOWLEDGE IS KING。AIの出力の差はプロンプトやセンスじゃなくて、情報を渡せているかどうかで決まります。入れる前は誰にでも書ける一般論が出てきて、入れた後はあなたの言葉で返ってきます。

商品説明・料金・特典・よくある質問・お客様の声。

誰に届けるのか。悩み・言葉づかい・アンケートやヒアリングの記録。

入れ方：メモを放り込むのもAIに任せる

メモを放り込むのすら面倒だと思うので、ここはAIに情報を渡して、適切なフォルダの中に入れてもらいましょう。渡し方は3つのどれでもOKです。①過去の投稿や商品説明の文章をチャット欄に貼り付ける ②ファイル（PDF・Word・メモ）をチャット欄にドラッグして添付する ③AI経営フォルダの中にファイルを入れておく。そのあとで、こう頼みます（③の場合は文頭に「さっき入れたファイルを」を足してください）。

STEP 04

ツールを繋ぐ（API・MCP と、僕がよく使う5つ）

ここまでだと、AIはパソコンの中でしか働けません。カレンダーやメールやSNSにある仕事も、繋いで任せられるようにします。

先に言葉だけ

API（外部のサービスとAIをつなぐ窓口みたいなもの。使うには「鍵」＝APIキーが要ります）と、MCP（APIの仲間で、AIと外部ツールを連携する仕組み）。やること自体は「繋ぐだけ」です。

繋ぎ方（3ステップ）

1

「サービス名 API」で検索して、専用サイトへ行く

APIやMCPはツールごとに入手方法が違いますが、基本的には「サービス名 API」とネットで調べれば専用サイトに行けます。そこでAPIキー（その鍵。人に見せてはいけない。パスワードと同じ扱いにする）を発行します。

2

鍵は「.env」という設定ファイルにしまう（チャットに直接貼らない）

APIキーは、銀行口座の暗証番号のようなものです。絶対に他人に見せてはいけませんし、AIのチャット欄にそのまま貼るのもダメです（会話の中に残って、流出する懸念があります）。代わりに .env という設定ファイルに入れて、AIにはそのファイルを読ませます。ファイルを作るところからAIに頼めます。

3

実際に繋ぐのは、使いたいツールが出てきた時でOK

いきなり全部繋がなくて大丈夫です。仕事の中で「これAIにやらせたい」が出てきた時に、そのツールだけ繋いでください。

APIキーを .env に入れさせるプロンプト（鍵そのものは書かない） 
APIキーを発行したから、.envファイルに入れたい。

STEP 05

スキル構築（競合Xリサーチを1個のスキルにする）

同じ指示を毎回打っていたら、それは自動化じゃないですよね。なのでスキルにします。

環境とツールが揃うと、AIに頼めば大体の仕事はできるようになります。ただ、同じ指示を毎回打っていたら、それは自動化じゃない。なのでスキルにします。スキルというのは、AIに渡す仕事マニュアルのようなもので、一言指示するだけで、同じ仕事が何回でも再現されます。僕はよく「必殺コマンド」って呼んでいます。

例：競合のX投稿リサーチを、1個のスキルにする

参考にしている競合のX投稿を引っ張ってきて、伸びている投稿を分析して、分析内容をGoogleドキュメントに入れる。X と AI と Googleドキュメントで、ツールを3つ跨いでいますよね。でもAPIを繋いであるから、これが1個のスキルで完結するんです。

3

次からは、一言で発動する

これで次からは、下の一言だけでこのスキルが発動して、さっきの流れを全部やってくれます。これが必殺コマンドです。発動しない時は、スキル化した時にAIが教えてくれたスキル名で呼ぶか、「さっき作ったXリサーチのスキルを実行して」と言えばOKです。

作ったスキルを呼び出す一言 
Xのリサーチして

ここでのポイント

  1. 作るときは「1機能1スキル」最初から万能なやつを作らない。1つの作業に1つのスキルです。
  2. ズレがあったら、日本語でフィードバックしていく「ここはこうして」と伝えるだけでスキルが直ります。回すほどズレが減っていきます。
  3. 作る → 使う → 直すこれを回せば回すほど賢くなっていきます。僕はこれで、今の時点で260本くらいスキルがあります。SNSも経理も動画編集も全部です。1本作るたびに、自分の仕事が1個AIに移っていく感覚です。

STEP 06

定期自動実行（スキルを毎朝勝手に動かす）

スキルができても、自分で毎回実行していたら時間が取られます。完璧になったスキルは、決めた時間に自動で動かします。

Claude Code にはスケジュール機能（Claude Code デスクトップアプリの「スケジュール設定されたタスク」）があって、時間を決めて登録するだけです。登録は下のプロンプトをチャットで送るだけでOKです（アプリのスケジュール一覧の画面からも作れます）。例えば、STEP5で作った競合リサーチのスキルを毎朝8時に回るように登録すると、明日から毎朝、伸びている投稿のパターンが勝手に集まってきます。

Codex を使っている人へ：この章の手順は Claude Code のスケジュール機能を前提に書いています。Codex の場合は、Codex の公式ドキュメントで定期実行にあたる機能を確認してください。
